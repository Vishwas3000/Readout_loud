Privacy Policy

Kokoro Reader Chrome Extension · Last updated: April 2025

100% Local — No Data Leaves Your Device

Overview

Kokoro Reader is a text-to-speech Chrome extension that converts webpage text to audio using the Kokoro-82M AI model running entirely on your local machine. No audio, text, or personal data is ever sent to any external server or third party.

Data We Collect

We collect no data whatsoever. Specifically:

  • We do not collect browsing history or page content
  • We do not transmit the text you select to any remote server
  • We do not store audio recordings
  • We do not use analytics, telemetry, or crash reporting services
  • We do not use cookies or tracking pixels

How It Works (Locally)

When you select text and click "Read", the extension sends that text exclusively to a local Python server running on localhost:8880 on your own computer. The Kokoro-82M model processes the text entirely on your hardware (CPU, GPU, or Apple Silicon MPS) and returns audio that is played directly in your browser. Nothing leaves your machine.

Permissions

The extension requests the following Chrome permissions:

  • storage — saves your voice/speed preferences locally in Chrome's sync storage
  • activeTab — reads selected text from the current tab when you initiate reading
  • scripting — injects a minimal content script to detect text selection and show the read button
  • contextMenus — adds a right-click "Read with Kokoro" option
  • offscreen — plays audio in a background document (Chrome MV3 requirement)
  • localhost:8880 — communicates with the local Kokoro TTS server on your machine only

Third-Party Services

This extension does not integrate with any third-party service. The Kokoro-82M model weights are downloaded once from Hugging Face during initial server setup — this is a one-time download to your local machine and is not required for ongoing use.

Data Storage

Your preferences (selected voice, playback speed, server URL) are stored using Chrome's built-in chrome.storage.sync API — saved to your Chrome profile and synced across your own devices only. No preference data is sent to us.

Changes to This Policy

If we make changes to this privacy policy, we will update the "Last updated" date above. Since no data is collected, changes will only occur if new features are added that affect data handling — and we will always err on the side of more privacy, not less.
